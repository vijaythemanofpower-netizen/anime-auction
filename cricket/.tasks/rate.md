# Task: turn the researched stats into game ratings

Work only inside this folder. Do NOT run git. Change only: `tools/rate.mjs` (new, plain Node, no dependencies; esbuild/vite-node may not run in your sandbox), `src/engine/data/ratings.ts` (new, generated by the script), and `src/engine/data/players.ts` (apply the generated ratings). You may delete `tools/rate.ts` (superseded).

## Input
`.tasks/stats/batch-1..5.csv` plus the corrections `.tasks/stats/batch-fa.csv` and `batch-fb.csv` (a row there replaces the same player's "no data" row). Header (fields may be quoted):
name,role,bowl,bats,t20_inns,bat_avg,bat_sr,sixes_per_inn,vs_spin,vs_pace,t20_overs_bowled,econ,bowl_sr,pp_skill,death_skill,speed_kmh,keeper,source

## Output: `src/engine/data/ratings.ts` (generated, with a "generated by tools/rate.mjs, do not edit" header)
`export const RATINGS: Record<string, { role, bowl, bats, bat: {vsPace,vsSpin,tempo,power,consistency}, bowling?: {attack,control,powerplay,death,speed}, keeping?: number, tier: 1|2|3|4|5 }>` keyed by real name. Import the types from `../types`.

## Formula (document it at the top of rate.mjs; tune constants so the scale below holds)
- consistency from batting average (avg 10 -> ~25, 25 -> ~60, 35 -> ~80, 45+ -> ~92); tempo from strike rate (SR 100 -> ~40, 130 -> ~68, 150 -> ~85, 170+ -> ~95); power from sixes per innings (0.2 -> ~30, 1.0 -> ~70, 1.8+ -> ~92). Shrink toward a modest baseline when t20_inns is small (fewer than ~20 innings).
- vsPace / vsSpin: a base from consistency and tempo, then +6 for "strong", -8 for "weak".
- Bowling (when overs bowled > ~20): control from economy (6.5 -> ~90, 7.5 -> ~78, 8.5 -> ~62, 10+ -> ~40), attack from bowling strike rate (14 -> ~92, 18 -> ~78, 22 -> ~62, 28+ -> ~45); powerplay/death from the skill words (elite 90, good 78, average 64, poor 48) blended with control; speed from speed_kmh (spinners 0). Part-timers (few overs) land 35-55.
- Tail-enders with empty batting: batting 10-30. Keepers get keeping 60-92 (better for known keepers).
- tier from overall value (best of batting/bowling, all-rounders blended): about 15 at tier 5, ~40 tier 4, rest spread; "no data" players tier 1 with modest ratings.

## Apply in players.ts
Use RATINGS[realName] to override role, bowl, bats, bat, bowling, keeping and tier for every player (the existing FIX table can go; keep `export const FIXED_NAMES: string[] = []` if tests import it). basePrice: keep the current value for players with no `prev` (their real registered base price); for others set it from tier (5: 200, 4: 150, 3: 100, 2: 50, 1: 30). Keep invariants: overseas === (country !== 'IND'); (bowl === 'none') === !bowling; pace/spin roles have bowling; pacers speed 110-160, spinners 0; keeping only when role is keeper.

## Check
Run `node tools/rate.mjs` to generate ratings.ts, then `node tools/check-roster.mjs`, and `npx tsc --noEmit -p .` if allowed. Write `.tasks/rate.result.md`: the formula, the top 10 batters and bowlers by rating (sanity check), tier counts.
